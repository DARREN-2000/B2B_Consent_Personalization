# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Comprehensive enterprise-grade documentation utilizing MkDocs Material theme.
- Governance, Security, and Contribution guidelines.
- GitHub Issue templates and Dependabot configuration.

## [1.0.0] - Initial Release

### Added
- Core Python/Flask backend API for Consent Policies and Consent Records.
- Multi-tenant Organization isolation.
- JWT-based Role-Based Access Control (RBAC).
- Vanilla JS Single Page Application (SPA) dashboard.
- Export functionality (CSV/JSON).
- Demo Mode with browser-based API mocking.
- Docker multi-stage builds.
- Production-ready Kubernetes Helm chart.
- GitHub Actions CI/CD pipeline.
