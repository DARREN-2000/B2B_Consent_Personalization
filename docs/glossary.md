# Glossary

| Term | Definition |
|------|------------|
| **Data Subject** | The individual whose personal data and consent is being managed (the end-user). |
| **Organization** | A tenant within the B2B platform. Data is strictly isolated between organizations. |
| **Consent Policy** | A definition of what is being consented to (e.g., "Marketing Emails v1.2"). |
| **Consent Record** | An immutable audit entry representing a Data Subject's decision regarding a specific Policy. |
| **JWT** | JSON Web Token; the mechanism ConsentHub uses for stateless authentication. |
| **RBAC** | Role-Based Access Control; limits API access based on the user's assigned role (`admin`, `editor`, `viewer`). |
